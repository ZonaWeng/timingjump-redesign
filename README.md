# 臺灣玻璃館網站優化

以 Vue 3 + Vite 製作的網站改版專案，重新規劃臺灣玻璃館的資訊架構、視覺介面與使用流程。

本專案為前端職業訓練期間完成的團隊專題，針對臺灣玻璃館網站進行介面、資訊架構與使用流程優化。
